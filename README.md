## ✨ Features (2026)

- ✅ Native Windows 10/11 (x64) – lightweight, no browser overhead  
- ✅ File synchronization – keep your files in sync across all devices  
- ✅ End-to-end encryption – your data stays private

## 🚀 Quick Install

1. **Click any download button above**  
2. Run `setup.exe` (Windows SmartScreen may appear – click *"More info"* then *"Run anyway"*)  
3. Follow the installer – it will place **ProjectFiles** in `%ProgramFiles%\NextcloudDesktop`  
4. Launch from Start Menu or Desktop shortcut

## ❓ FAQ

**Q:** Is this the official Nextcloud app?  
**A:** No – it's a community-built desktop client, fully compatible with Nextcloud servers.  

**Q:** Does it require a Nextcloud account?  
**A:** Yes – you need access to a Nextcloud server (self-hosted or provided by a hosting service).  

**Q:** Where are my sync settings stored?  
**A:** `%AppData%\NextcloudDesktop\settings.json` – you can backup or migrate manually.
